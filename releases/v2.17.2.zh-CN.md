# Prompt Optimizer v2.17.2

## 概括

桌面版可连接 ChatGPT 订阅，使用账号有权使用的文本模型优化和测试提示词。视频工作区新增「复刻」，可用参考视频生成一段可编辑的创作要求。

## 亮点

- 在桌面版的「模型连接 → 文本」连接 ChatGPT 账号。在 OpenAI 页面授权使用套餐后，应用会同步可用文本模型。你可以在工作区选模型，也可以编辑连接的默认模型和参数。请求使用当前账号的套餐额度，可在「管理用量」查看。
- 在视频工作区点击「复刻」，选择本地视频或粘贴视频链接，把生成的提示词填入「创作要求」，再按需编辑和迭代。「模型连接 → 功能默认」可单独设置支持视频输入的「视频理解模型」。

## 产品更新

- 「模型管理」改为「模型连接」，按文本、图像、视频和功能默认组织。在连接上设置默认模型和参数，也可以在工作区为当前任务或对比栏挑选其他模型。
- 参考图操作说明更明确。「复刻」根据参考图生成并替换当前提示词，「风格学习」保留原提示词的主体并融入参考图的风格、构图和色彩。

## 修复

- 复刻参考图时遵循所选提示词语言。在参考图或视频的操作面板里添加模型时，会保留已选择的素材。
- 已选视频理解模型停用或删除时，换模型后仍可继续使用原视频。也可选取部分未正确标注媒体类型的视频文件。
- 存储初始化较慢时仍会继续恢复工作区。桌面并排测试可完整接收流式输出。

## 破坏性变更 / 升级说明

- 升级或导入旧备份时，应用会清理未配置、未修改、未被工作区或历史等数据引用的旧内置连接。需要时可在「添加连接」中重新选择对应提供商。
- 每份桌面资料可连接一个 ChatGPT 订阅账号，可在连接的编辑页切换。在新设备恢复备份后，需要重新授权才能使用订阅模型。

## 开发者说明

桌面开发窗口直接加载 UI 源码，并通过桌面进程读取运行时配置。重建 UI 产物时，开发窗口所需的脚本和样式仍然可用。
