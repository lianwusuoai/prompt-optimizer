# Prompt Optimizer v2.17.1

## Summary

Connect a ChatGPT subscription in the desktop app to optimize and test prompts with eligible text models. In the Video workspace, use **Replicate** to turn a reference clip into an editable creative brief.

## Highlights

- Connect ChatGPT under **Model Connections → Text** in the desktop app. After you grant plan access on OpenAI's sign-in page, the app syncs the text models available to your account. Choose a model in the workspace, or edit the connection's default model and parameters. Requests count toward the connected account's plan allowance. Select **Manage usage** to review it.
- Choose **Replicate** in the Video workspace and select a local clip or paste a video URL. Use the resulting prompt as your creative brief, then edit or revise it. Under **Model Connections → Function Defaults**, choose a **Video Understanding Model** that accepts video input.

## Product Updates

- **Model Connections** now organizes text, image and video connections alongside function defaults. Set a connection's default model and parameters, then choose a different model for a task or comparison column as needed.
- The reference image actions explain what they do. **Replicate** generates a prompt from the reference and replaces the current prompt. **Style Learn** keeps the current subject and incorporates the reference's style, composition and colors.

## Fixes

- Reference image replication respects the selected prompt language. The reference image or clip stays selected when you add a model from its action panel.
- If the selected video understanding model is disabled or removed, choose another model and continue with the same clip. The picker also accepts common video files that lack a specific media type.
- Workspace recovery continues when storage initialization takes longer than expected. Desktop comparison columns now receive their complete streamed results.

## Breaking Changes / Upgrade Notes

- On upgrade or when importing an older backup, the app clears old built-in connections that were never configured or changed and have no references in workspaces, history or other saved data. Use **Add Connection** to set up those providers again.
- Each desktop profile can connect one ChatGPT subscription account. Switch accounts from the connection editor. When you restore a backup on a new device, authorize the account again to use its subscription models.

## Developer Notes

The desktop development window loads UI source and reads runtime settings through the desktop process. Rebuilding the UI bundle now leaves the scripts and styles required by the running development window available.
