# 模型连接调整方案

沿用现有配置和下拉框。一条连接保存提供商、账号或服务地址、默认模型和默认参数。同一提供商可以有多条连接。工作区和功能默认可以沿用连接的默认模型，也可以指定该连接下的其他模型及局部参数。例如「公司网关」默认使用模型 A，测试 B 列选了模型 B，这一列就通过公司网关调用 B。其他列继续使用各自的选择。

## 用户会看到什么

| 位置 | 调整 |
| --- | --- |
| 模型连接 | 工具栏、弹窗和工作区的管理入口统一称为「模型连接」。四个页签为「文本」「图像」「视频」「功能默认」。功能页里的「评估模型」「图像识别模型」等保留具体用途。 |
| 连接列表和表单 | 工具栏提供「添加连接」。列表操作为「测试连接」「编辑」「复制」。主标题用连接名称，副行标「默认模型」。同一服务商的多条连接可分别命名。表单沿用「提供商配置」。「默认参数」默认折叠，有改动时显示「已设 N 项」。 |
| 桌面 ChatGPT 订阅 | 未连接时，「添加连接」旁的 ChatGPT 图标和表单里的订阅选项共用授权入口。同步到模型后，当前账号在文本列表占一行，支持测试、编辑和启停。「编辑」可修改连接名称、默认模型和参数，也可刷新模型、切换账号、管理用量和断开连接。列表测试使用已保存的默认模型，编辑页测试使用表单当前选择。目录为空或授权不完整时，显示账号状态和恢复操作。 |
| 工作区和功能默认 | 沿用现有下拉，按连接选择具体模型，标明参数只作用于当前位置。收起时优先显示模型名，同名模型能看清连接来源。无可用连接时可直接去「添加连接」。选用订阅时保留「使用 ChatGPT 套餐」和「管理用量」。 |

订阅只在桌面注册账号有权使用的文本模型。授权沿用现有流程，首次套餐提示和用量入口遵循 [OpenAI 交互规范](https://developers.openai.com/siwc/ui-ux-guidelines)。

## 内置提供商的默认连接和清理

- 提供商模板保留在「添加连接 → 提供商配置」中。新资料只列用户添加、已完成授权或确有有效环境配置的连接。环境配置按各提供商的字段判断，例如 Cloudflare 要检查账号 ID 和令牌，用户配置的免密本地服务也算有效连接。复用本地服务发现入口。
- 文本目前在初始化时补齐缺失的内置 ID，列表同时隐藏这些 ID 的删除操作。图像列表可以删除，但初始化同样会补回缺项。两处都要把模板和实际建档分开。用户主动停用或删除环境变量生成的连接，重启后尊重这个选择，可手动启用或重新添加。自动清掉出厂空项后，将来首次配上有效环境变量仍可生成连接。[文本初始化](../../packages/core/src/services/model/manager.ts) · [文本列表](../../packages/ui/src/components/TextModelList.vue) · [图像初始化](../../packages/core/src/services/image-model/manager.ts)
- 视频首次读取空资料时会给一条 Seedance 默认配置，已保存的空列表会保持为空。新资料可从添加表单选择这个预设。保留现有视频任务对连接的依赖检查，已有视频配置按自身状态处理。[视频配置读取和删除](../../packages/core/src/services/video-model/manager.ts)
- 升级时自动清理能确认的旧空项。需要同时满足旧版出厂预置、停用、设置仍是出厂值、没有有效环境配置、没有被保存的选择引用。核对名称、地址、请求头、协议、默认模型和参数等用户可能改过的值。检查所有已保存工作区、测试列、功能默认和历史里的直接 ID 及组合引用。用户显式设置过、旧版默认值无法确认或引用读取不完整的记录保留，并允许手动删除。导入旧备份时，在相关数据导入完成后应用相同规则，重复执行结果一致。

## 桌面订阅的模型选择

授权成功后为当前账号建立一条文本连接，工作区下拉框列出该账号同步到的模型。首次同步失败时可重试，清单为空时显示「暂无可用文本模型」。用户选中模型后，参数面板显示该模型支持的选项，实际请求使用所选模型和当前位置的参数。桌面主进程按当前账号的订阅目录校验请求目标。[订阅适配器](../../packages/core/src/services/llm/adapters/chatgpt-subscription-adapter.ts) · [桌面账号和目录校验](../../packages/desktop/config/chatgpt-subscription.js)

## 验收用例

- 无环境配置的新资料能直接添加提供商。环境配置有效时连接可用，主动删除后重启不会重现，再次添加可恢复。
- 一份旧资料同时含出厂空项、改过地址但停用的连接、免密本地连接和被其他工作区引用的连接。升级和重复导入都只清理出厂且无引用的空项。
- 桌面用模拟订阅返回模型 A 和 B。连接列表显示一个账号。在两个测试列分别选择 A 和 B，核对两次请求各自使用的模型 ID 和参数。
